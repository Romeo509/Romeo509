## 🛠️ Tech Stack

| Layer | Tech |
|-------|------|
| Front‑end | **Next.js** (React, TypeScript) – [Docs](https://nextjs.org/docs) |
| Back‑end  | **Express** (Node.js, TypeScript) – [Docs](https://expressjs.com/en/guide/routing.html) |
| Database  | **Neon** – Postgres backends for apps and agents (server‑less PostgreSQL) – [Neon](https://neon.com) – via **Prisma** ORM |
| Deployment | **Vercel** – frontend hosting ([Docs](https://vercel.com/docs)) – **Koyeb** – backend runtime ([Website](https://app.koyeb.com/)) |
| Self‑host | **Pocket Base** – perfect for personal or test projects ([Pocket Base](https://pocketbase.io/)) |
